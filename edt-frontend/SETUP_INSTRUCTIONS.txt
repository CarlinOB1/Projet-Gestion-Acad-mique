🚀 COMPLETE SETUP STEPS:
────────────────────────────────────────────────────────────────────────

1️⃣  CREATE ALL DIRECTORIES & FILES:

    Windows (easy):
    $ .\setup.bat

    OR All platforms:
    $ npm run setup

    This creates all 13 remaining files in the correct directories!


2️⃣  INSTALL DEPENDENCIES:

    $ npm install

    Installs:
    - React 19
    - Vite 8
    - React Router 7
    - TanStack Query 5
    - Zustand 5
    - Axios
    - Tailwind CSS 3
    - shadcn/ui components (Radix UI, CVA)
    - And more...


3️⃣  CONFIGURE ENVIRONMENT:

    The .env file already has the default API URL:
    VITE_API_BASE_URL=http://localhost:8000/api

    Update if your backend runs on a different URL.


4️⃣  START DEVELOPMENT SERVER:

    $ npm run dev

    ✓ Opens http://localhost:3000
    ✓ HMR enabled (hot reload)
    ✓ API proxy working (/api → localhost:8000)


5️⃣  BUILD FOR PRODUCTION:

    $ npm run build

    Creates optimized dist/ folder

🆘 TROUBLESHOOTING:
────────────────────────────────────────────────────────────────────────

Q: "setup.bat not working"
A: Run: npm run setup (works on all platforms)

Q: "Module not found: '@/...'"
A: Make sure npm install completed. Check jsconfig.json has correct paths.

Q: "Cannot find ./node_modules"
A: Run npm install first

Q: "Port 3000 already in use"
A: Either kill the process or modify vite.config.js server.port

Q: "API calls returning 404"
A: Check .env VITE_API_BASE_URL matches your backend URL
