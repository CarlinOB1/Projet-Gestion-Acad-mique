                          ⏳ FILES TO BE CREATED

These files will be automatically created when you run: npm run setup

API Layer (src/api/):
──────────────────────────────────────────────────────────────────────────────
  ⏳ client.js
     - Axios instance with custom headers
     - Request interceptor: Injects Bearer token
     - Response interceptor: Handles 401 with token refresh
     - Automatic redirect to login on refresh failure

  ⏳ auth.js
     - login(username, password) → POST /token/
     - refreshAccessToken(token) → POST /token/refresh/
     - logout() → Clears auth store

State Management (src/store/):
──────────────────────────────────────────────────────────────────────────────
  ⏳ authStore.js
     - Zustand store with persistence
     - State: accessToken, refreshToken, user, isAuthenticated
     - Actions: setAuth, setAccessToken, clearAuth
     - Selectors: selectIsResponsable, selectIsEnseignant, selectIsEtudiant

Routing (src/routes/):
──────────────────────────────────────────────────────────────────────────────
  ⏳ index.jsx
     - React Router v7 configuration
     - Protected routes for each role
     - Redirect logic: / → /role/planning based on user role
     - Error pages: 404, 403

  ⏳ ProtectedRoute.jsx
     - Route guard component
     - Validates authentication & role
     - Redirects unauthorized users to /login or /unauthorized

Features (src/features/):
──────────────────────────────────────────────────────────────────────────────
  ⏳ auth/LoginPage.jsx
     - Login form UI (Card, Input, Label, Button)
     - Auto-redirect if already authenticated
     - Error message display
     - Ready for mutation integration

Utilities (src/lib/):
──────────────────────────────────────────────────────────────────────────────
  ⏳ utils.js
     - cn() - Merge Tailwind classes (clsx + twMerge)
     - formatHeure() - Convert "09:00:00" → "09h00"
     - formatDate() - Convert "2025-10-01" → "Mer. 1 oct."
     - getDureeLabel() - Calculate session duration minus 11h-11h15 break

  ⏳ constants.js
     - ROLES: { RESPONSABLE, ENSEIGNANT, ETUDIANT }
     - TYPE_SEANCE: { CM, TD, TP }
     - STATUT_SEANCE: { CONFIRMEE, ANNULEE, REPORTEE }
     - SEANCE_COLORS & STATUT_COLORS for UI
     - HEURE_MIN & HEURE_MAX for business logic

UI Components (src/components/ui/):
──────────────────────────────────────────────────────────────────────────────
  ⏳ card.jsx - Card layout components
  ⏳ button.jsx - Button with variant system (default, outline, ghost, etc.)
  ⏳ input.jsx - Form input with Tailwind styling
  ⏳ label.jsx - Form label with Radix UI

                          🚀 HOW TO GET STARTED
═══════════════════════════════════════════════════════════════════════════════

STEP 1: CREATE REMAINING FILES
────────────────────────────────────────────────────────────────────────────

Windows (Easy):
  $ .\setup.bat

OR any platform:
  $ npm run setup

This creates 13 files with complete implementations in:
  - src/api/
  - src/store/
  - src/routes/
  - src/features/auth/
  - src/lib/
  - src/components/ui/


STEP 2: INSTALL DEPENDENCIES
────────────────────────────────────────────────────────────────────────────

  $ npm install

Installs all required packages:
  - react@19.2.6
  - react-router-dom@7
  - @tanstack/react-query@5
  - zustand@5
  - axios@1
  - tailwindcss@3
  - And utilities (clsx, tailwind-merge, @radix-ui/*, etc.)


STEP 3: CONFIGURE ENVIRONMENT (Optional)
────────────────────────────────────────────────────────────────────────────

Edit .env if your backend runs on a different URL:
  VITE_API_BASE_URL=http://localhost:8000/api


STEP 4: START DEVELOPMENT
────────────────────────────────────────────────────────────────────────────

  $ npm run dev

✓ Server starts on http://localhost:3000
✓ HMR (Hot Module Reload) enabled
✓ API proxy working (/api calls → localhost:8000)


STEP 5: BUILD FOR PRODUCTION
────────────────────────────────────────────────────────────────────────────

  $ npm run build

Creates optimized dist/ folder ready for deployment
